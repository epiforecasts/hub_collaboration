# hub_collaboration

> **Archived.** No longer maintained; last updated April 2022.

A draft document, "Collaboration on the hub tooling", proposing guidelines for teams running modelling hubs on developing shared infrastructure together. It draws on standards bodies such as the IETF and W3C, on the tidyverse team's practices and on general software conventions such as semantic versioning.

- `index.qmd`: the Quarto source of the draft; `index.html` is the rendered version.
- `concept_map.svg`: concept map of a modelling hub used in the document; `w3c_process.svg` illustrates the W3C process.
